# AI usage record

This record documents source annotations for AI-assisted implementation work in PicoOS. It follows the University of Freiburg [Academic Writing Guide](https://uni-freiburg.de/ska/wp-content/uploads/sites/186/AcademicWritingGuide_2025.09.29.pdf)'s documentation principles by analogy. The guide concerns academic writing and does not explicitly prescribe source-code documentation.

## Source annotation record

This table lists every AI-assisted file, function, and test fixture covered by this record. Every `*.picoc` source listed for an OS or shell test contains the same `// AI used: GitHub Copilot through GitHub Education` annotation used elsewhere in the repository. The test runner consumes `input.txt`, `expected_output.txt`, and auxiliary fixture data verbatim, so their AI use is recorded through the linked test-directory entry instead of comments that would change the test. The test entries exclude `test/hello_world`, the separate boot test, and all library tests. In every case, the author had already defined the intended behavior and implementation approach. Copilot accelerated repetitive implementation or debugging work rather than deciding PicoOS concepts, architecture, algorithms, or core mechanisms.
